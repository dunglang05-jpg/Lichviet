# Ca kiểm

Đáp án đối chiếu lấy từ bộ ca kiểm của thư viện Nhật Nguyệt
(https://github.com/Nhat-Nguyet/nhatnguyet-lunar-ziwei-bazi-numerology, thư mục `ca-kiem/`),
phát hành theo giấy phép Creative Commons Attribution 4.0 (CC BY 4.0), © Nhat Nguyet (nhatnguyet.org).
Đã chuyển sang dạng phẳng, nén gzip để kiểm tự động:

- `tu-vi.txt.gz`: 777 lá số Tử Vi (an sao, đại vận, hạn năm 2026, sao lưu, cách cục).
- `duong-sang-am.tsv.gz`: đổi dương sang âm theo giờ Việt Nam (ngày âm, can chi, sao Nhị thập bát tú).
- `am-sang-duong.tsv.gz`: đổi âm sang dương.
